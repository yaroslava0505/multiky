# Мультфільми за темами

Статичний сайт-каталог: 42 мультфільми й серіали, посортовані за вісьмома темами —
дружба, підтримка, емоції, доброта, смілість, сімʼя, бути собою, втрата.
Для кожної назви: вік, тривалість, де це легально дивитися в Україні
і питання для розмови з дитиною після перегляду.

## Структура

```
src/data.js    ← УВЕСЬ контент: 42 мультфільми + теми, категорії, вікові групи
src/index.html ← розмітка головної (пошук, фільтри, сітка, модальне вікно)
src/app.js     ← логіка: пошук, фільтри, обране, модалка, випадковий мультик
src/style.css  ← стилі
src/art/       ← картинки: hero.webp, <тема>.webp, <id мультфільму>.webp
build.py       ← генератор: збирає docs/ із src/
docs/          ← готовий сайт, саме його віддає GitHub Pages
```

Сторінок: головна з пошуком і фільтрами, 8 сторінок тем, 42 сторінки мультфільмів,
«Про каталог», 404. Жодних залежностей і фреймворків — Python 3 для збірки,
чистий Vanilla JS у браузері.

## Збірка

```
python3 build.py
```

Подивитися локально:

```
cd docs && python3 -m http.server 4174
```

→ http://localhost:4174

## Як додати мультфільм

Усе в одному файлі — `src/data.js`. Скопіюйте будь-який обʼєкт у масиві `MOVIES`
і замініть значення:

| Поле | Що це |
|---|---|
| `id` | латиницею, стане адресою `/mult/<id>/` і іменем картинки |
| `title`, `originalTitle` | назва українською та оригінальна (обидві шукаються) |
| `poster` | `art/<id>.webp`; якщо файлу немає — покажеться заглушка з літерою |
| `age`, `ageMin` | група (`0–3 роки`, `3–6 років`, `6–9 років`, `9+ років`) і число |
| `family` | `true`, якщо підходить для перегляду всією родиною |
| `format` | `short` (до 10 хв), `series` (10–25 хв) або `full` |
| `categories` | з переліку в `CATALOG_META.categories` |
| `themes` | ключі тем: `friend`, `help`, `feel`, `kind`, `brave`, `family`, `self`, `loss` |
| `description` | про що мультфільм |
| `value` | чим корисний, на що зважати |
| `question` | питання для розмови після перегляду |
| `watchLinks` | масив `{name, url}` — посилання на пошук у сервісі |

Картинку покладіть у `src/art/<id>.webp` (співвідношення приблизно 16:10).
Потім `python3 build.py` — сторінки, перелінковка й sitemap перезберуться самі.

## Публікація на GitHub Pages

1. Створіть на github.com порожній **публічний** репозиторій `multiky`
   (на безкоштовному тарифі Pages працює лише з публічних).
2. У `build.py` замініть `SITE_URL` на адресу сайту, наприклад
   `https://ваш-логін.github.io/multiky`, і запустіть `python3 build.py` —
   зʼявляться `sitemap.xml`, `robots.txt` і canonical-теги.
3. Підключіть репозиторій і відправте код:

```
git remote add origin https://github.com/ВАШ-ЛОГІН/multiky.git
git add -A && git commit -m "Оновлення каталогу"
git push -u origin main
```

4. У репозиторії: **Settings → Pages → Source: Deploy from a branch**,
   гілка `main`, папка **/docs**. Через хвилину сайт буде за адресою
   `https://ваш-логін.github.io/multiky/`.

Файл `docs/.nojekyll` уже є — він вимикає обробку Jekyll, інакше GitHub
ігнорує частину файлів.
